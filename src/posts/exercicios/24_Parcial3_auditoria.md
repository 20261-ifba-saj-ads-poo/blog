# Trabaho - Entrega final

Realizar a **entrega completa do trabalho**, incorporando as seguintes funcionalidades:

1. **Tela de Login**

   - Implementar uma tela de autenticação para acesso ao sistema.
   - O acesso deverá ser realizado mediante usuário e senha.

2. **Cadastro de Usuários**

   - Implementar o cadastro e gerenciamento dos usuários do sistema.
   - O sistema deverá possuir dois perfis de acesso:

     - **COMUM**: acesso às funcionalidades padrão do sistema.
     - **ADMIN**: acesso às funcionalidades padrão e às funcionalidades administrativas (Tela de Auditoria).

3. **Tela de Auditoria**

   - O usuário com perfil **ADMIN*- deverá ter acesso a uma tela de auditoria.
   - Nessa tela deverá ser possível consultar, para cada registro:

     - **quem realizou a inclusão do registro**;
     - **quando o registro foi inserido**;
     - **quem realizou a última alteração**;
     - **quando o registro foi modificado pela última vez**.

4. **Adequação da arquitetura**

   - Realizar todas as alterações necessárias na arquitetura do sistema para suportar as novas funcionalidades.
   - Adequar as interfaces `Service` e `DAO`, o `AbstractModel` e demais classes, interfaces, entidades e componentes que forem necessários.
   - Garantir que as alterações sejam realizadas de forma consistente com os padrões e princípios já utilizados no projeto.

A entrega deverá contemplar **todas as funcionalidades implementadas e integradas ao sistema**, mantendo a organização e a coerência da arquitetura existente.
