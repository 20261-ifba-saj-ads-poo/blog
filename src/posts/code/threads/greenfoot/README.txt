COMO USAR ESTE CÓDIGO NO GREENFOOT:

1. No seu projeto do Greenfoot, crie uma subclasse de World chamada 'MeuMundo'.
2. Substitua o código de 'MeuMundo.java' pelo arquivo correspondente deste ZIP.
3. Crie uma subclasse de Actor chamada 'Personagem' e coloque o código de 'Personagem.java'.
4. Crie uma classe Java pura no Greenfoot (ou arquivo .java na pasta do projeto) chamada 'ClienteHandler' com o código fornecido.
5. Compile o Greenfoot. O servidor vai abrir automaticamente na porta 12345 assim que o mundo iniciar.

COMO CONTROLAR COM O CLIENTE:
1. Compile e execute a classe 'ClienteControle.java' no seu terminal ou em uma IDE como o BlueJ / VS Code.
2. Cada instância nova do 'ClienteControle' que você rodar vai criar um novo quadradinho azul no Greenfoot com a identificação do ID (ex: C1, C2).
3. Digite W, A, S ou D no terminal do cliente e aperte Enter para ver o personagem se mover no Greenfoot!
